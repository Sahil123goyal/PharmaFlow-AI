PharmaFlowAI Software Requirements Specification

Overleaf use
1. Create a project using Upload Project and select PharmaFlowAI_SRS_Overleaf.zip.
2. The main document inside the ZIP is main.tex.
3. Use the pdfLaTeX compiler. Recompile until contents and references settle.
4. Replace the bracketed author, roll number, institution, department, supervisor, course and submission-date values near the top of main.tex.
5. Download the compiled PDF from Overleaf after checking the title page.

The project is standalone: diagrams are drawn with TikZ and no image files, external bibliography or shell escape are required.

The document preserves the supplied reference's five-chapter hierarchy and identifies implemented, prototype and proposed features separately. Baseline date: 12 October 2026. Local tests: 85 Django tests and 9 JavaScript tests passed.

The editable original is PharmaFlowAI_SRS.tex; main.tex in the ZIP contains the same source.
